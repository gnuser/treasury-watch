# treasury-watch
Solo-built treasury & funding monitoring toolkit (Rust + static dashboard).
Read-only. No keys, no trading, no leverage.

## What it does
- Polls lending-market positions, computes health factors, flags depeg/concentration risk
- Tracks CEX perpetual funding rates vs fees → net APR snapshots
- One-command reports for DAO treasuries (holdings, yield breakdown, exposure)

## Live example
- Dashboard: `dashboard/index.html` (also served via GitHub Pages)
- Real pull: `docs/funding-rate-snapshot-2026-09-18.md` — Binance/Bybit/OKX
  public APIs, majors net ~4–8% after taker fees
